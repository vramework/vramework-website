# S3

S3-compatible object storage (AWS, MinIO, DigitalOcean Spaces).

```bash
npm install @pikku/addon-s3
```

Category: **Cloud** · Version: `0.1.6` · Package: `@pikku/addon-s3`

## Functions

| Function | Description | Services |
| -------- | ----------- | -------- |
| `s3CopyObject` | Copy an object within or between S3 buckets | `s3Client` |
| `s3CreateBucket` | Create an S3 bucket | `s3Client` |
| `s3DeleteBucket` | Delete an S3 bucket | `s3Client` |
| `s3DeleteObject` | Delete an object from S3 | `s3Client` |
| `s3GetObject` | Download an object from S3 | `s3Client`, `content` |
| `s3ListBuckets` | List all S3 buckets | `s3Client` |
| `s3ListObjects` | List objects in an S3 bucket | `s3Client` |
| `s3PutObject` | Upload an object to S3 | `s3Client`, `content` |

## Secrets

- `S3_CREDENTIALS` — S3-compatible object storage credentials

## Wiring it up

Declare the addon once, then reference its functions the way you would your own:

```typescript title="addons.wiring.ts"
import { wireAddon } from '#pikku/addon'

wireAddon({
  name: 's3',
  package: '@pikku/addon-s3',
})
```

The `name` becomes the namespace its functions are called under. See [Consuming addons](/docs/addon/consuming) for the declare/wire rule and how `ref()` resolves.

# Addons

**218 addons** shipping **5812 functions** between them. An addon is a package of pikku functions someone else already wrote — you declare it once, and its functions become callable from yours through `ref()`, with the same types, permissions and tree-shaking as your own code.

```bash
npm install @pikku/addon-<name>
```

See [Addons](/docs/addon) for how to wire one up, and [writing an addon](/docs/addon) if you want to publish your own.
